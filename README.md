# Descomplicador de NFe / NFe Explorer
Aplicativo Delphi VCL que processa XMLs localmente, apresenta fornecedor, CNPJ, data, número e total, identifica arquivos inválidos e exporta CSV UTF-8. Nenhum documento sai do computador.

Abra `NFeExplorer.dpr` no Delphi 13 ou compile com `dcc32 NFeExplorer.dpr`.

---
Local-only Delphi VCL application that consolidates NFe XML files and exports a UTF-8 CSV report.
